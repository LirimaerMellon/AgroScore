# AgriScore

Система скоринга заявок на сельхозсубсидии на основе машинного обучения.

---

## Что это делает

- Загружает исходные данные
- Выполняет очистку и подготовку
- Формирует признаки
- Обучает модель
- Рассчитывает скоринговую оценку заявок
- Классифицирует заявки по категориям (HIGH / MEDIUM / LOW)
- Сохраняет результаты в Excel файл

---

## Структура проекта

```
data/
├── raw/        # входные данные
├── debug/      # промежуточные файлы (для отладки)
├── results/    # результаты скоринга
├── models/     # обученные модели

app/
├── pipeline/
├── train.py
├── config.py
```

---

## Требования

- Windows, Mac или Linux
- Python 3.10+

## Установка

1. Установите Python 3.10+

2. Установите зависимости:

```bash
pip install -r requirements.txt
````

## Запуск проекта (обучение и скоринг)

Входной файл уже имеется в папке raw. Файл называется "data".

```
data/raw/data.csv
```

Выполните команду:

```bash
python app/train.py --input data/raw/data.csv
```

Это запустит процесс загрузки даных и обучения модели.

---

## Результаты работы

После запуска будут автоматически созданы:

### Результаты скоринга:

```
data/results/result_YYYYMMDD_HHMMSS.xlsx
```

### Обученная модель:

```
data/models/model_YYYYMMDD_HHMMSS.pkl
```

### Debug файлы:

```
data/debug/
 ├── raw_data.csv
 ├── cleaned_data.csv
 ├── with_target.csv
 ├── enriched_data.csv
```

Они используются для анализа этапов обработки данных.

---

## Как работает пайплайн

1. Загрузка данных
2. Проверка обязательных колонок
3. Очистка данных
4. Формирование целевой переменной (target)
5. Feature engineering
6. Обучение модели
7. Скоринг заявок
8. Сохранение результатов

---

## Важные требования к данным

* Должны присутствовать необходимые колонки (см. validate_columns)
* Данные должны содержать статусы заявок
* Для обучения требуется размеченная целевая переменная (target)

Пример статусов:

* Исполнена
* Одобрена
* Отклонена
* Отозвано
* Получена
* Сформировано получение

---

## Категории скоринга

Модель делит заявки на:

* **HIGH** — высокая вероятность / приоритет
* **MEDIUM** — средняя вероятность
* **LOW** — низкая вероятность
